APMS.ai - what to upload over FTP
========================================

Host is Hostinger (LiteSpeed + PHP). There is no build step: the
repository root IS the site, so this is a straight copy.

Upload to the web root (public_html), keeping the folder structure.

  .htaccess is a dotfile. Most FTP clients hide it by default, and
  without it you lose HTTPS redirects, the old WordPress URL
  redirects, the 404 page, caching and the security headers. Turn on
  "show hidden files" or it will look like it uploaded and it will
  not be there.

  config.php is NOT in this list and is NOT in the repository. Copy
  config.sample.php to config.php on the server and fill in the
  database details. Without it the form still works and still keeps
  every enquiry in the CSV, it just does not write to MySQL.

This list is generated, not hand-kept. To refresh it after adding or
removing files, re-run the generator in the scratchpad rather than
editing here: the hand-kept version drifted and left five
stylesheets off, which shipped a site with broken styling.
