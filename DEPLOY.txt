APMS.ai - what to upload over FTP
========================================

Host is Hostinger (LiteSpeed + PHP). There is no build step: the
repository root IS the site, so this is a straight copy.

Upload to the web root (public_html), keeping the folder structure.

  .htaccess is a dotfile. Most FTP clients hide it by default, and
  without it you lose HTTPS redirects, the old WordPress URL
  redirects, the 404 page, caching and the security headers. Turn on
  "show hidden files" or it will look like it uploaded and it will
  not be there.

  config.php is NOT in this list and is NOT in the repository. Its
  shape is documented in the header of submit.php: create it there
  and fill in the database details. Without it the form still works
  and still keeps every enquiry in the CSV, it just skips MySQL.

This list is generated, not hand-kept. To refresh it:

    node tools/deploy-list.js

Do that after adding or removing any file, and always after
`node tools/bundle.js` changes a bundle - the hashed filename is in
this list, so a stale list names a bundle that no longer exists.

Do not edit the list by hand. It has drifted twice. The first time it
left five stylesheets off and shipped a site with broken styling. The
second time it listed every source file under css/ but none of the
built bundles under dist/css/, which are the only stylesheets the
pages actually link - so following it would have uploaded a full set
of CSS that nothing references, and shipped an entirely unstyled
site. assets/fonts/, js/core/gsap-late.js and llms.txt had gone
missing too.

The generator used to live in a scratchpad, which is why it was never
re-run. It is in tools/ now, and it fails loudly if any page links a
file the list does not include.
